# 🔠 Tokenizer Playground

🚀 **Explore how LLMs tokenize text!** This interactive playground allows you to input any text and visualize how different tokenizer models process it. Compare tokenized outputs, understand token IDs, and analyze byte-level tokenization.

## ✨ Features

✅ **Interactive Tokenization** – Enter text and see how tokenization works in real time.  
✅ **Token Breakdown** – View the generated tokens along with their unique token IDs.  
✅ **Multiple Models** – Compare tokenization results using different pre-trained tokenizers.  
✅ **Byte-Level Details** – Check how BPE-based models break words into subword units.

## 🛠️ How It Works

- Select a **tokenizer model** (e.g., BERT, GPT-2, XLM-RoBERTa).
- Enter text in the input field.
- The tool **tokenizes the text** and displays:
  - Tokenized words/subwords
  - Token IDs
  - Byte-level representations (for BPE models)
